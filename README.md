# La caperucita roja - Factoria F5

El primer proyecto de aprendizaje para Factoria F5

## Objetivo
Hacer una pagina web usando HTML y CSS mientras se aprende a usar el comando git de forma correcta.

## Descripción de página
Una web minimalista que cuenta la historia de la caperucita roja con varios capitulos que son accesibles mediante un botón, una indexación y imagenes vistosas en cada uno.
